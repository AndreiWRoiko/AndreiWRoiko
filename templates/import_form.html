Como Importar
  1. Prepare uma planilha Excel com as colunas necessárias
  2. Preencha os dados seguindo os requisitos abaixo
  3. Salve como arquivo Excel (.xlsx ou .xls)
  4. Faça o upload usando o formulário abaixo
Dicas importantes:
  • O campo Patrimônio deve ser único para cada equipamento
  • Campos obrigatórios: Responsável, UF, Centro de Custo, CNPJ, Modelo e Patrimônio
  • Para campos Sim/Não, use: "Sim", "Não", "True", "False", "1", "0"
  • Datas devem estar no formato DD/MM/AAAA
  • Valores monetários podem usar R$ e separadores de milhar
